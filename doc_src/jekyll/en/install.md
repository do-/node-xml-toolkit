# Installation
## Prerequisites

All you need is [node.js](https://nodejs.org/en/download) v.14 or newer.

## Setup

Just execute

```sh
npm install xml-toolkit
```

or, if you prefer [yarn](https://classic.yarnpkg.com/en/):

```sh
yarn add xml-toolkit
```

That's it.
